# Site Friends

Site estático sobre a série Friends, desenvolvido durante o ensino médio com HTML e CSS.

O conteúdo apresenta personagens, episódios marcantes, curiosidades e o legado da série, acompanhado por imagens relacionadas ao programa.

## Tecnologias

- HTML5
- CSS3

## Como visualizar

Abra o arquivo `index.html` em um navegador ou acesse a versão publicada:

https://jullia1908.github.io/site-friends/

## Contexto

Este projeto foi produzido como atividade de aprendizagem para praticar estruturação de páginas, estilização e organização de conteúdo visual.
